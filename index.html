Set up the trend history feed

This section hasn't found any history data yet. It reads a sheet tab where one new row is added each day — unlike the rest of the dashboard, which overwrites a single row.

In the same Google Sheet used by the rest of the dashboard:

1. Add a tab named History (or similar) with this header row:

Date, DemandFillRate, GrossProfitPercent, LostSales, InventoryOnHand, ExcessInventory, MonthsSupply, PartsSalesToday, Aging6to11, Aging12plus

2. Add one row per day — either by hand, or automatically with the Apps Script in GOOGLE_SHEETS_SETUP.md.

3. Publish that tab to the web (Share → General access → Anyone with the link) and get its gid the same way as the other feeds.

4. Paste the resulting CSV URL into TREND_CSV_PATH in this file's <script> section, then commit.
